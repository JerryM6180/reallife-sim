# 人生模拟器

一个跑在浏览器里的中国当代人生模拟器。一格时间是一个月，一个月你只能干一件事 —— 这是全部的规则。DEMO 从 2026 年 9 月、16 岁的高中开始，跑到 26 岁那一格为止，中间会经过 2028 年 6 月的高考、填志愿、毕业和找工作。

**在线试玩：https://jerrym6180.github.io/reallife-sim/**

纯 JavaScript，没有框架，没有 npm，没有任何运行时依赖。要出单文件版的时候用一次 Python，就这一处。

---

## 玩法

每一格时间，你从 9 个动词里挑一个，再从这个动词下面挑一件具体的事：

**工作 / 学习 / 搞钱 / 房产 / 社交 / 家庭 / 身体 / 休息 / 人生决策**

一共 45 个行动，能不能点由你现在的阶段（高中 / 大学 / 工作 / 待业）和当下的条件决定 —— 没工作的时候「争取晋升」不在那里，但「找工作」在。

选完这一格就过去了。引擎结算收入和开销、身体和压力、家人和关系、行情，然后大约三成的概率撞上一件事；春节那一格是八成半，因为它是家庭关系的年度大考，不该被随机吞掉。在岗的时候，有 42% 的概率这次抽的是你这份工作特有的事件 —— 你干的这份活，得让你感觉得到。

职业上你进的不是一个岗位，是一条线。39 条线，一共 257 格。站在第几格由晋升决定，而晋升不是按钮一点就上去：干满年份是主项，绩效、专业等级、单位里有没有人替你说话、这两年在扩还是在收、越往上位置越少、你多大年纪了，全都在概率拆解里写着。失败了扣绩效，冷却 18 个月。

岗位板上的东西分三态：**可投**（条件全满足，薪资是真值）、**够不着**（看得见名字，薪资只给传闻区间，最多列两条你差什么）、**???**（还没发现，只有行业和一条粗略的薪资条）。还有第四态 —— 完全没接触过的行业，连 ??? 都不给。隐藏岗位靠八种途径进入你的世界：家里有人干这行、聊天聊出来的、在一个行业熬满三年、在这座城市住久了、一次折腾的副产品、专业等级过线看懂了、托人打听、刷到一条视频。你越是道听途说，薪资区间越宽；短视频那条还会往上说 22%。

风评是一个你在状态栏里找不到的数。它不是绩效 —— 绩效是季度的，风评是年头攒的。它只在提名单的那一刻起作用，也只有在晋升概率的拆解里才可能露一面：「这些年你办成过几件事」，或者「你手上出过事，有人记着」。

种子和当前格数一直显示在行动区底部。同一个种子 + 同样的选择 = 完全相同的一生。

## 怎么跑起来

```
git clone https://github.com/JerryM6180/reallife-sim.git
cd reallife-sim
```

### 开发：分文件

直接用浏览器打开 `index.html`。12 个 js 按固定顺序用 `<script src>` 加载，改完刷新就行，没有编译步骤。

浏览器限制 `file://` 的话，用仓库里的静态服务器：

```
python serve.py
```

然后打开 `http://127.0.0.1:8777/index.html`。

`index.html` 和单文件版用的是同一份样式，看到的就是完整的样子。

### 出包：单文件

```
python build.py
```

`build.py` 读 `build/shell.html`（完整的那份外壳样式，纸账本配色，跟随系统深浅色），把 12 个 js 按同样的顺序内联进去，写出 `build/reallife-demo.html`。它会打印字节数和内联的 script 数 —— 应该是 12。

产出的是一个 HTML 文件，双击就能玩，也可以直接发给别人。它在 `.gitignore` 里（每次构建整个文件都变，提交进去会把 diff 历史冲垮），所以克隆下来的仓库里没有，要自己跑一次。

外网取不到 Google Fonts 的时候，字体会退到系统的思源黑 / 苹方 / 微软雅黑，不影响玩。

存档是浏览器 localStorage 里的一个槽，key 是 `reallife_demo_save_v2`。清浏览器数据就没了。

## 代码结构

加载顺序是固定的，`index.html` 和 `build.py` 里写的是同一串。顺序有意义：`tracks_*` 要在 `jobtracks` 之前（不然没有线可挂），`jobtracks` 要在 `engine` 之前（它会改 `CONTENT.JOBS`），`ui` 最后。

| 文件 | 负责什么 |
|---|---|
| `js/rng.js` || mulberry32 种子随机。整个引擎只允许通过这里取随机。`next / int / float / chance / pick / weighted / shuffle / normal`，加上 `save / load`（存档要存住随机数状态）。不存在「幸运值」属性 —— 随机就是随机，不给玩家任何接口去影响它。 |
| `js/content.js` || 内容层，引擎不认识里面任何具体内容。10 座城市、9 种出身、6 个天赋、11 种疾病、10 个行业、109 条手写岗位、5 类高中、32 所大学、23 个专业、11 个理财标的、9 个动词下的 45 个行动、21 条通用事件、9 个传闻来源和 12 条传闻模板。职业线只在这里写了 1 条（银行）当样板，其余在 `tracks_*.js`。 |
| `js/tracks_a.js` || 职业线 · 第一批：体制内 / 教育 / 医疗，14 条。 |
| `js/tracks_b.js` || 职业线 · 第二批：互联网 / 金融 / 制造建筑，13 条。 |
| `js/tracks_c.js` || 职业线 · 第三批：服务 / 物流 / 文化传媒 / 法律，11 条。 |
| `js/jobtracks.js` || 把散岗接到职业线上。`MAP` 里 97 条写「它属于哪条线」，进哪一格由工资自动对齐；`NO_LADDER` 里 11 条写「这份工作真的没有下一格」，并且写清楚为什么。剩下 1 条岗位自带 `track`。没挂上也没写进 `NO_LADDER` 的会进 `CONTENT.JOBTRACK_REPORT.miss`。 |
| `js/jobevents_a.js` || 岗位遭遇事件 · 第一批：体制内 / 教育 / 医疗，29 条。 |
| `js/jobevents_b.js` || 岗位遭遇事件 · 第二批：互联网 / 金融 / 制造 / 建筑，23 条。 |
| `js/jobevents_c.js` || 岗位遭遇事件 · 第三批：服务 / 物流 / 文化传媒 / 法律，19 条。 |
| `js/events2.js` || 第二批通用事件，24 条。单独一个文件，方便继续往里堆。 |
| `js/engine.js` || 引擎，纯逻辑零 DOM。月度结算、税后工资与房租与生活成本、技能成长与专业等级、关口（高考 / 志愿 / 毕业 / 求职）、岗位三态与八种发现途径、晋升概率与结算、事件抽取、行情、疾病、NPC 与家庭、存读档。对外只暴露 `Engine.*`。 |
| `js/ui.js` || UI 层，只负责渲染和输入，所有规则都在 engine 里。开局页、左侧状态栏、中间时间流、行动区、折线图、行情窗口、岗位板、年表、结局、localStorage 存档。 |
| `build.py` || 把 `build/shell.html` 和上面 12 个 js 拼成 `build/reallife-demo.html`。它做的唯一一件额外的事是删掉 shell 里一个写错的空嵌套 CSS 块。 |

另外：`serve.py` 是个七行的静态服务器；`build/shell.html` 是单文件版的外壳（只有样式和一个 `#app`，script 由 `build.py` 追加）；`spec/gen.py` 从 `spec/ladders.json` 生成一份职业阶梯速查表，跟运行时无关。

## 怎么加内容

### 加一条职业线

在 `js/tracks_a.js` / `tracks_b.js` / `tracks_c.js` 任选一个按行业归类的位置，用文件顶上已经定义好的 `T()` 和 `r()`：

```js
T({ id: 'warehouse', name: '仓储履约', ind: '物流', tier: [1, 5], stopAt: 2,
  entry: { edu: ['高中'], majors: [], level: 0 },
  ranks: [
    r('拣货员', 5000, 4, 1, 2, 0, '一天走三万步。手持机上跳出来哪个货位就去哪个货位。'),
    r('复核员', 5800, 3, 1, 2, 0, '核对、打包、贴单。错一单要写情况说明。'),
    r('组长', 7000, 3, 1, 3, 0, '一个小组。大促那几天，仓库里的灯不关。'),
    r('履约规划', 20000, 3, 3, 4, 5,
      '不在仓库了，在办公室算网络布局。这一格开始要学历。',
      '这是这条线唯一一个坎：下面几格靠熬，这一格靠一张文凭。'),
  ] });
```

`T(o)` 做两件事：`C.TRACKS.push(o)` 和 `C.TRACK_MAP[o.id] = o`。

`r(name, g, i, p, y, lv, b, t)` 展开成 `{ name, gross, intensity, prestige, years, level, blurb, trap }` —— 职级名 / 杭州基准税前 / 强度 1-4 / 声望 1-5 / 升到下一格通常要几年 / 需要的专业等级 / 这一格的一句话 / 这一格的代价。`trap` 不是每格都有。最后一格 `years` 写 0。

`stopAt` 是多数人停在第几格，对玩家隐藏，只以传闻出现。`entry` 是这条线第一格的门槛。`exam: true` 表示要先考进去。`ceilingNote` 是「这条线的天花板取决于什么」，会被拿去当第一格的 `trap` 兜底。

写完不用注册。`engine.js` 的 `buildTrackEntries()` 会在开局时自动把每条线的第一格变成岗位板上的一个入口，id 是 `tk_<线id>`。

### 加一个岗位

在 `js/content.js` 的 `JOBS` 数组里加一条对象：

```js
{ id: "gray_offshore", name: "境外「支付／棋牌」项目 · 技术岗", ind: "互联网",
  gross: 28000, intensity: 4, prestige: 1, skill: 35, tier: [1, 2],
  edu: ["一本", "二本", "专科"], majors: [], level: 5, capital: 0, minYears: 1,
  hazard: true, noSocial: true, hidden: true,
  discover: "npc",
  blurb: "钱是两三倍，打过来是没有备注的。护照放在公司保险柜，说是怕丢。",
  trap: "没有合同，没有社保，断缴影响你落户、买房、孩子上学。……" },
```

`gross` 是杭州基准税前，引擎再乘城市系数。`tier` 限定它存在于哪几线城市。`edu / majors / level / capital / minYears` 是门槛，`engine.js` 的 `jobGates()` 挨个检查，差哪条就在岗位板上显示哪条（`hard` 越大的门越硬，显示时排前面）。`hidden` + `discover` 决定它一开始在不在你的世界里，`discover` 取值是 `family / npc / tenure / city / event / skill / ask / media` 之一 —— 不同途径的薪资传闻精度不一样。`blurb` 是干这行的人自己说的一句，`trap` 是这份工作真正的代价。

然后去 `js/jobtracks.js` 给它指一条线：

```js
const MAP = {
  /* ── 互联网 ── */
  algo: 'dev', bigtech_dev: 'dev', dev_mid: 'dev', dev_sme: 'dev',
  pm: 'pm', game_numeric: 'pm',
  ...
};
```

进哪一格不用填。`rankByPay()` 按工资找最接近的那一格，并且夹一道 —— 至少留一格可升，否则接上线和没接上是一回事。

真的没有下一格的，写进 `NO_LADDER`，并且写清楚为什么：

```js
const NO_LADDER = {
  shop_owner: '你就是老板。上面没有人了 —— 往上只能是开第二家店，那是另一回事。',
  ghost_writer: '没有署名，也就没有职级。写得越好越没人知道你写过。',
};
```

这句话会显示在「争取晋升」的位置上。玩家该看见「这里到头了」，而不是看见按钮凭空消失。

两边都没写的岗位会被记进 `CONTENT.JOBTRACK_REPORT.miss`，在控制台里敲一下就能看到。

### 加一个岗位事件

在 `js/jobevents_a.js` / `b` / `c` 里用 `J()`：

```js
J('guard', {
  id: 'kg_night', maxRank: 2, weight: 17, cooldown: 20,
  title: '夜班',
  text: () => '监控室，凌晨三点。十六块屏，没有一块在动。',
  options: [
    { label: '（无法选择）', apply: (c) => {
      const { E, rng } = c;
      E.health(-1.6); E.stress(+4);
      return R([
        '你把整栋楼的巡更点走了一遍，回来是四点二十。剩下的两个小时你盯着屏幕，什么也没想。',
        '你在监控室看完了一整部电视剧。天亮的时候交班，接班的那位问你昨晚有没有事，你说没事。',
        '有一块屏突然动了一下，是只猫。你盯着它走出画面。',
      ], c.rng);
    } },
  ],
});
```

`J(线id, o)` 拼出触发条件：在这条线上、在岗、`minRank` 到 `maxRank` 这个职级区间内、在这份工作上干够 `after` 个月（默认 5），再加上可选的 `cond(s)`。它给事件打上 `job: true`，抽事件的时候这类有单独的份额。默认 `weight: 16`、`cooldown: 30`。

`apply(c)` 拿到 `c = { s, E, rng, d }`，返回一句话当这个月的记录。`R(arr, rng)` 是每个文件顶上那行随机取一条的小工具。

能改的量都挂在 `E` 上：`E.cash / E.health / E.stress / E.perf / E.rep / E.raise / E.promo / E.skill / E.rel / E.relGroup / E.flag / E.schedule / E.quitJob / E.moveCity / E.rumorNow …` 全表在 `engine.js` 的 `const E = {`。`E.rep` 就是风评。

通用事件（不绑岗位的）用 `js/events2.js` 里的 `ev()`，字段是 `when / weight / cooldown / tier / title / text / options`，`auto: true` 表示不给选项、直接出结果。

## 设计原则

这几条不是口号，是代码里已经这么写了的：

**每个选项都有代价，没有纯赚的那一项。** 材料改到满意要扣健康加压力，而且有一半概率第二天用的是别人那版；拼一版交上去省了力气，之后这种活就不找你了 —— 在机关里这不是好事。写事件的时候如果有一个选项明显是对的，那这个事件就还没写完。

**数值藏在角色不会知道的地方。** 天赋不显示数值，只在结果上体现。风评不在状态栏里，只在提名单那天起作用。`stopAt`（多数人停在第几格）对玩家隐藏，只以传闻出现。够不着的岗位不给真薪资，只给传闻区间 —— 家里人说的偏差 8%，中介 25%，短视频 40% 而且还会往上说两成。阶层不是一个数值，它只影响起点资源、容错空间、信息半径和社会期望四件事。

**随机不暴露给玩家。** 所有随机只从 `rng.js` 走，一个入口。玩家看不见掷点，也没有任何接口能影响它 —— 运气不可控、不可刷、不偏向玩家。玩家能看见的只有种子，以及「同一个种子 + 同样的选择 = 完全相同的一生」这一条承诺。这一条顺带让 bug 可复现：报 bug 的时候附上种子和你按的顺序就够了。

**按钮不凭空消失。** `promoStatus()` 返回四种状态：没工作 / 这个岗位本来就没有台阶 / 到顶了 / 在冷却，每一种都有一句话说清楚是哪一种。按不动比消失好，说清楚为什么按不动比按不动好。

**刷不出数值。** 连着重复同一件事，收益会衰减；技能越接近上限涨得越慢；同样刷一个月题，在省重点和在乡镇中学不是一回事。

**大量平淡日子。** 基础事件触发率压在 0.30，出过的次数越多再出的权重越低。人生的大部分月份什么都没发生，这是有意的。
